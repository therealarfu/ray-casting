# ray-casting
It's a Ray Casting Algorithm in C with gaming controllers support, deltatime and SDL library.

# Controls
``WASD`` Move
``LEFT AND RIGHT`` Camera rotation

# How to use
```
make run
```
Or
```
gcc main.c -o raycasting -lmingw32 -lSDL2main -lSDL2
```
